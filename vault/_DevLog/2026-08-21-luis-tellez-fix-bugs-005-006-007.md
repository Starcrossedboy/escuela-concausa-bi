## Qué se hizo

### 1. BUG-005: Scripts .sh rotos en Windows (CRÍTICO)

**Causa raíz:**
Windows con `core.autocrlf=true` convierte LF → CRLF al checkout. Los scripts con
CRLF rompen el shebang (`#!/bin/sh\r`) dentro de contenedores Linux.

**Síntomas reportados:**
- Superset: `$'\r': command not found`
- MLflow: `no such file or directory` (el archivo existe, no encuentra el intérprete)

**Solución implementada:**
Agregar a `.gitattributes`:
```
*.sh text eol=lf
```

Esto fuerza LF en todos los sistemas, independiente del `core.autocrlf` local.

**Archivos afectados:**
- `docker/mlflow-entrypoint.sh`
- `docker/superset-init.sh`
- `docker/chromadb-entrypoint.sh`
- `scripts/verificar-servicios.sh`
- Todos los .sh del proyecto

**Impacto:** Desbloquea a TODOS los desarrolladores en Windows (~50% del equipo).

### 2. BUG-006: Healthchecks falsos (ALTA)

**Problema 1 - API:**

`docker-compose.yml` definía:
```yaml
healthcheck:
  test: ["CMD", "curl", "-f", "http://localhost:${API_PORT}/health"]
```

**Problema:** La imagen `python:3.11-slim` NO tiene curl instalado.

**Contexto adicional:** `docker/api.Dockerfile` línea 23-24 SÍ define un healthcheck
correcto usando python:
```dockerfile
HEALTHCHECK CMD python3 -c "import urllib.request; urllib.request.urlopen(...)"
```

Pero `docker-compose.yml` lo overridea con uno que usa curl.

**Solución:** Remover el healthcheck del compose, dejar que herede el del Dockerfile.

**Problema 2 - ChromaDB:**

Healthcheck apuntaba a `/api/v1/heartbeat` que retorna `410 Gone` (deprecated).

**Solución:** Actualizar a `/api/v2/heartbeat` + agregar `start_period: 10s`.

**Impacto:** En la demo del 9 sept se verían servicios en rojo. Si alguien agrega
`depends_on: condition: service_healthy`, el stack no levantaría.

### 3. BUG-007: Puerto MLflow confuso (MEDIA)

**Problema:**
`guia-ambiente-local/VERIFICACION.md` decía `localhost:5000` cuando el mapeo real es
`127.0.0.1:5001:5000` (puerto externo 5001, interno 5000).

**Solución:**
Actualizar documentación: 5000 → 5001.

**Impacto:** Solo confundía a nuevos usuarios.

## Aprendizajes

### Técnicos

1. **Line endings críticos en Docker:** LF vs CRLF rompe shebangs. `.gitattributes`
   es la solución de fondo, no configurar `core.autocrlf` por máquina.

2. **Healthchecks en compose vs Dockerfile:** `docker-compose.yml` overridea el
   `HEALTHCHECK` del Dockerfile. Si el del Dockerfile es correcto, mejor no definir
   uno en compose.

3. **ChromaDB v1 deprecated:** El endpoint `/api/v1/heartbeat` retorna `410 Gone`.
   Usar `/api/v2/heartbeat`.
